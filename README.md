有读者一看到“但需要指出”就想起 GPT。这份整理顺着这个印象去找原帖，既看某个词有没有出现，也看不同的人是否遇到了同一种说话方式。

## 一句话怎么进主表

每项观察至少有三条独立来源链支持。转载同一张截图、引用同一段对话、在同一帖子里继续讨论，都合并计数。整理时分别记录模型原话、用户转述和用于说明的例句，也记下版本、任务和相反体验。比如 DeepSeek 的碎短句集中在小说和故事写作里，这条观察就限定在写作场景。

材料以贴吧和技术社区中主动分享的使用体验为主。表格里的数字统计的是收集到的资料，估计实际使用频率还需要另外抽样。详细口径见[阅读说明与对照](输出/阅读说明与对照.txt)，每条观察对应的来源编号见[全部研究条目 JSON](输出/全部研究条目.json)。

## 补充和纠错

欢迎开 Issue 提交近半年的材料。请附**原帖链接、对话或反馈日期、模型和使用场景**，再贴上能看出这个说法的几句原文。如果是使用者回忆，也请顺手注明。指出哪条被过度概括，或提供相同场景下的不同体验，都有帮助。
